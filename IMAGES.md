## Как заменить изображение

### Вариант 1. Просто заменить файл (самый простой)

1. Подготовьте новую картинку **того же размера и пропорций**, что и старая.
2. Сохраните её в WebP с тем же именем: например, `facade-800.webp`.
3. Замените файл в `assets/media/`.
4. Если у фото есть второй размер (`-480` и `-800`), замените **оба** — иначе на телефоне может остаться старая версия.
5. Обновите страницу с очисткой кэша: `Cmd + Shift + R` в браузере.

Пересобирать сайт после замены картинок не нужно. Сборка (`python3 tools/build.py`) нужна только если вы меняете HTML/текст.

### Вариант 2. Новое фото с другими пропорциями

Тогда стоит обновить не только файл, но и разметку:

- в HTML у `<img>` есть атрибуты `width` и `height` — поставьте реальные размеры новой картинки;
- если фото входит в `srcset`, подготовьте все указанные размеры;
- если пропорции сильно другие, проверьте, как работает `object-fit: cover` в конкретном блоке (фото может обрезаться по краям);
- для карточек товаров и больших фото лучше сохранять те же пропорции, что и раньше.

### Как сделать WebP на Mac

Встроенный `sips` умеет обрезать и менять размер, но **не умеет сохранять WebP**. Удобные варианты:

**Без установки программ:** откройте [squoosh.app](https://squoosh.app), перетащите фото, выставьте качество 80–85 и скачайте WebP. Там же можно задать нужный размер.

**Через Homebrew (если пользуетесь терминалом):**

```bash
brew install webp
```

Пример для фото 3:2 (как `facade-800.webp`):

```bash
# обрезать по центру до 800×536
sips -c 536 800 source.jpg --out /tmp/facade-800.jpg
# сохранить в WebP
cwebp -q 82 /tmp/facade-800.jpg -o assets/media/facade-800.webp

# уменьшенная версия
sips -z 321 480 /tmp/facade-800.jpg --out /tmp/facade-480.jpg
cwebp -q 82 /tmp/facade-480.jpg -o assets/media/facade-480.webp
```

Для hero (1920×780) используйте `sips -c 780 1920`, для этапов производства — `sips -c 456 800` и `sips -z 274 480`.

### Сорта пива

Файлы `beer-*.webp` — это бокал на белом фоне, 340×520. В CSS используется `mix-blend-mode: multiply`, поэтому белый фон растворяется на карточке. Можно заменить и на фото с прозрачным фоном — тоже будет работать. Главное: бокал по центру, примерно одинаковая высота у всех пяти сортов.

### Логотип и иконки

- Замените `logo-192.png` и `logo-384.png`. Они используются в шапке, подвале, возрастной проверке, водяных знаках и соцпревью.
- `assets/favicon-32.png` и `assets/favicon-180.png` лучше сделать отдельно: **квадратными**, с логотипом по центру и отступами. Не растягивайте прямоугольный логотип в квадрат.
- Если поменялся логотип, обновите и `og-cover.jpg` — иначе при отправке ссылки будет старая картинка.

```bash
# если есть квадратная иконка 180×180
sips -z 32 32 assets/favicon-180.png --out assets/favicon-32.png
```

### Награды

Сканы дипломов лежат в `award-*.webp`. Их лучше не сжимать слишком сильно: текст должен читаться в лайтбоксе. Оптимально — 700 px по ширине и качество WebP 80–85.

## Если меняете имена файлов

Тогда придётся обновить ссылки в:

- HTML-страницах в корне (и в `src/pages/`);
- `src/partials/` — если картинка в шапке/подвале;
- `assets/css/style.css` — фоновые изображения и водяные знаки;
- JSON-LD на главной (`logo`, `image`);
- `site.webmanifest` — иконки.

После этого:

```bash
python3 tools/build.py
```

## Кэш

Браузеры и телефоны любят держать картинки в кэше. Если заменили файл, а видите старое:

- на компьютере — `Cmd + Shift + R`;
- на iPhone — закройте вкладку и откройте заново; если не помогло: «Настройки → Safari → Очистить историю и данные»;
- радикальный способ — добавить к имени версию: `facade-800-v2.webp` и обновить ссылки в HTML.

## Оригиналы

Оптимизированные картинки лежат в `assets/media` и именно они публикуются. Исходные большие фото храните **вне папки сайта**, например в `~/Pictures/tarussky-gus/`, и уже из них готовьте WebP. Тогда при желании всегда можно пересобрать нужный размер без потери качества.

Фотографии и логотип принадлежат пивоварне; перед передачей сайта подрядчикам проверьте права на изображения.
