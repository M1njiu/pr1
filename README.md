# Пивоварня «Тарусский гусь» — новый сайт

Информационный статический сайт пивоварни в Тарусе. Без корзины, оплаты и онлайн-продаж: только рассказ о производстве, сортах, экскурсиях, фирменном магазине и поставках.

## Что внутри

- **9 страниц:** главная, о пивоварне, продукция, сотрудничество и экскурсии, магазины, галерея, контакты, политика конфиденциальности, 404.
- **Адаптивный дизайн** для десктопа, планшета и телефона (проверено от 320 px).
- **Локальные шрифты** Unbounded, Manrope и Lora — без обращений к Google Fonts.
- **Оптимизированные WebP-изображения**, `srcset` для крупных фото и ленивая загрузка.
- **Доступность:** семантические заголовки, alt-тексты, видимый фокус, скип-ссылка, поддержка `prefers-reduced-motion`, навигация без JS.
- **Возрастная проверка** с сохранением подтверждения в `localStorage`.
- **Галерея с лайтбоксом**, карта Яндекс Карт, форма, которая открывает почтовую программу.
- **SEO:** title/description, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`, `site.webmanifest`.

## Как посмотреть

Самый простой способ — запустить локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

Затем открыть [http://localhost:8000](http://localhost:8000).

Можно открыть `index.html` и напрямую двойным кликом, но для корректной работы встроенной карты и некоторых браузерных ограничений лучше локальный сервер.

### Проверка на телефоне

1. Подключите Mac и телефон к одной Wi-Fi-сети.
2. Запустите сервер с доступом по сети:

   ```bash
   cd /Users/ni/Documents/deepseek-harness/default-workspace
   python3 -m http.server 8000 --bind 0.0.0.0
   ```

3. Узнайте IP-адрес Mac:

   ```bash
   ipconfig getifaddr en0
   ```

   Если команда ничего не вывела, посмотрите адрес в «Системные настройки → Wi-Fi → Подробности». Обычно это что-то вроде `192.168.0.34`.
4. Откройте на телефоне `http://192.168.0.34:8000` (подставьте свой IP). Важно: `localhost` на телефоне указывает на сам телефон, а не на Mac.
5. Если macOS спросит разрешение для Python на входящие подключения — разрешите.

Проверьте вручную: меню-гамбургер, возрастную проверку, карточки сортов, «липкую» навигацию на странице продукции, галерею с лайтбоксом, карту, форму и телефонные ссылки. Отдельно стоит открыть страницу на ширине 320–390 px и повернуть телефон горизонтально.

Возрастная проверка запоминается в браузере. Чтобы увидеть её снова: в Safari на iPhone — «Настройки → Safari → Очистить историю и данные», в Chrome на компьютере — DevTools → Application → Local Storage → удалить ключ `tg-age-confirmed`.

Если телефон и Mac в разных сетях или Wi-Fi изолирует устройства, можно временно опубликовать папку на Netlify Drop / GitHub Pages либо открыть туннель (например, `ngrok http 8000`).

### Быстрая проверка без телефона

- **Chrome:** ⌥⌘I → значок устройства (⌘⇧M) → iPhone 14 Pro / Pixel 7.
- **Safari:** меню «Разработка» → «Режим адаптивного дизайна» (⌃⌘R).

Эмулятор не заменяет реальный телефон: на нём стоит проверить Safari, прокрутку, клавиатуру в форме и работу карты.

## Структура

```
index.html, about.html, ...   готовые страницы сайта
assets/css/style.css          стили
assets/js/main.js             меню, лайтбокс, форма, анимации
assets/fonts/                 локальные WOFF2-шрифты
assets/media/                 изображения и иконки
assets/favicon-*.png          иконки сайта
src/layout.html               общий каркас страницы
src/partials/                 шапка, подвал, возрастная проверка, лайтбокс
src/pages/                    исходники страниц
tools/build.py                сборщик страниц
preview/                      скриншоты для быстрого просмотра
```

## Как править контент

Тексты и разметка страниц лежат в `src/pages/`. Шапка, подвал и общие блоки — в `src/partials/`. Стили — в `assets/css/style.css`.

После правок в `src/` пересоберите сайт:

```bash
python3 tools/build.py
```

Сборщик обновит HTML в корне, `sitemap.xml` и `robots.txt`. Нужен только Python 3.9+, никаких npm-зависимостей.

Если правки небольшие и делать сборку не хочется, можно менять готовые HTML в корне напрямую — но при следующей сборке такие правки затрутся.

## Перед публикацией

1. **Проверьте факты:** стоимость и продолжительность экскурсии (400 ₽ / 30 минут), режим работы магазина, телефоны и наличие сортов. Эти данные взяты с текущего сайта и могут меняться.
2. **Форма обратной связи** работает через `mailto:` — открывает почтовую программу посетителя. Данные никуда не отправляются автоматически. Если нужны заявки на сервере, подключите backend или сервис форм (Formspree, Getform и т. п.) и замените обработчик в `assets/js/main.js`.
3. **Возрастная проверка** хранится на стороне браузера. Для строгого соответствия требованиям площадки или рекламного размещения может понадобиться серверная проверка.
4. **Домен.** Все абсолютные ссылки в SEO и `sitemap.xml` сейчас ведут на `tarusskiygus.ru`. Если домен изменится, поменяйте `BASE_URL` в `tools/build.py`, пересоберите сайт.
5. **Политика конфиденциальности** — рабочий шаблон под текущую функциональность сайта. Перед публикацией стоит показать его юристу.
6. **Карта** встроена через `yandex.ru/map-widget/v1` без API-ключа. Если понадобится другой вид карты, замените iframe на API или статичное изображение.
7. **Фотографии и логотип** взяты с действующего сайта пивоварни и принадлежат владельцу. Перед передачей сайта третьим лицам проверьте права на изображения.
8. **Хостинг.** Загрузите в корень сайта всё, кроме `src/`, `tools/` и `preview/`. Настройте страницу 404 на `404.html`. Сайт полностью статический, подойдёт любой хостинг или GitHub Pages/Netlify.

## Технические детали

- Палитра: глубокий зелёный `#0f2a21`, кремовый `#f5f0e3`, янтарный `#e2a94a`.
- Типографика: Unbounded для заголовков, Manrope для текста, Lora italic для акцентов.
- Цветовые токены и компоненты — в начале `assets/css/style.css`.
- Анимации отключаются при `prefers-reduced-motion: reduce`.
- Для мобильной навигации без JavaScript предусмотрен `<noscript>`-фолбэк.
- Галерея использует нативный `<dialog>` и доступна с клавиатуры.
